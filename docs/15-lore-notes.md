# 15 — Lore Notes

Thirty readable Special Items, distributed across the ten areas. These are the game's entire lore
delivery mechanism ([00](00-overview.md), pillar 3) and **every one of them is optional.**

## Rules

1. **A note is never about the plot. It's about a person's Tuesday.** The plot is what a player
   assembles from thirty of them. Any note that summarizes, explains, or warns has failed.
2. **Written by people who didn't know anyone would read this.** Real documents: notices, schedules,
   letters, forms. No diaries addressed to nobody, no convenient exposition.
3. **Permanently kept and re-readable** from the bag ([06](06-items-and-equipment.md)). A player
   should be able to sit down at hour 11 and re-read note #4 and have it mean something different.
4. **No note names Vixtry's actual purpose.** The officers say it out loud in Act 4; the notes never
   do. Notes only ever show the shape of it from underneath.
5. **The family name is never rendered.** See the proposal at the bottom of this document.

## PROPOSAL — the family name is never rendered

The game refuses to display the protagonist's surname anywhere, ever. It appears exactly three
times, and all three are dodges:

| Where | How |
|---|---|
| Act 0, the parents arguing | `▓▓▓ ▓▓▓▓` — the same block glyphs as everything else through that door. |
| Act 3, the Vixtry grunt | *"Same last name as one of the hardware guys."* Spoken, never printed. |
| Act 4, note #26 | `D. ▓▓▓▓▓▓` on a staff roster, in a document where thirteen other surnames render fine. |

This costs one glyph and one rule, it uses a motif the prologue already establishes, and it means
the single most important word in the game is the one word it will not show you. The player enters
a first name at file creation and is never asked for the rest.

**It also quietly answers a production problem** — the player-entered name can't be made to match a
surname on a document, so the document simply doesn't have one to match.

The `D.` is the only thing about the father the game ever prints.
